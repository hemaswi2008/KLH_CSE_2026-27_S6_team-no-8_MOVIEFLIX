MOVIEFLIX FINAL IMPLEMENTATION
==============================

This folder contains:
- MovieFlix.java
- MovieFlix_Final_Dataset.csv
- DATASET_SOURCE_NOTE.txt
- DATASET_INFO.txt

IMPORTANT:
Keep MovieFlix.java and MovieFlix_Final_Dataset.csv in the SAME folder.

Java version:
JDK 8 or later.

Run in VS Code Terminal:
    javac MovieFlix.java
    java MovieFlix

The program supports:
1. Display all movies
2. HashMap exact title search
3. Binary Search title search
4. KMP keyword/pattern matching
5. Fuzzy matching using Levenshtein distance
6. Merge Sort by title
7. Merge Sort by release year
8. Search by language
9. Search by genre
10. Add movie
11. Update movie
12. Delete movie
13. Save dataset
14. Reload dataset
15. Complete algorithm execution demo
0. Exit

DO NOT modify the dataset manually before the first test.
We will demonstrate dataset changes step-by-step after confirming the
program loads and runs correctly.
